# 会計人プロフィール（Accounting Profile）

会計士・税理士・経理・受験生のための**プロフィールメーカー**です。49問のLikertと7つの選択操作から、5つの独立したレイヤーで「あなたの会計人としての輪郭」を可視化します。

**ビルド不要の静的サイト**（Vanilla JS + ES Modules）。サーバーを持たず、採点も結果表示もすべてブラウザ内で完結します。

```bash
node scripts/dev-server.mjs
```

→ http://localhost:4173

---

## 結果はサーバーに保存されません

このアプリにはバックエンドがありません。**構造的に、回答も結果も外部へ送信されません。**

| 項目 | 扱い |
|---|---|
| 回答内容 | ブラウザ内でのみ保持。送信しない |
| 採点・結果生成 | すべてクライアントサイド |
| 一時保存 | `localStorage` に**回答途中の下書きのみ**。中断したユーザーが最初から答え直さずに済むようにするための一時保存 |
| 結果の保管 | **行わない**。結果画面を閉じると同じ結果は再取得できない |
| 共有リンク | `#p=CODE.pct.pct.pct.pct` はURLフラグメントのためサーバーへ送信されない。含まれるのは Work Style 4軸とアーキタイプのみ |
| 外部リクエスト | Google Fonts（Shippori Mincho・明朝体のフォールバック）と、ユーザーが押した場合のみ X の共有画面。いずれも回答データは含まない |

`localStorage` に置くキーは次の2つだけです。

- `kprofile.v1` — 回答途中の下書き（`ans` / `ops` / `page`）。トップ画面の「この端末の下書きを削除」または結果画面の「もう一度作る」で消去
- `kprofile.autoAdvance` — 自動で次ページへ進むかの設定

### 結果を残せるのは、回答直後のその場だけ

サーバーに保管しない以上、結果を手元に残す手段はダウンロードだけです。この点はUI上でも明記しています。

- トップ画面の PRIVACY パネル（回答を始める前に予告）
- 結果画面上部の警告アラート（回答直後）
- 詳細を読み終えた位置の再掲パネル（詳細を見ている間）

ダウンロードは2形式です。どちらもブラウザ内で生成し、送信は行いません。

| 形式 | 内容 |
|---|---|
| **PNG プロフィールシート** | 5レイヤーすべてを1枚にした縦長画像（1080×約2500 @2x）。SNS投稿・保管用 |
| **JSON データ** | 回答の生データ（項目単位）とスコア。トップ画面の「保存したデータを読み込む」で結果を再表示できる |

ダウンロードボタンを出すのは**自分の回答から確定した結果を表示しているときだけ**です。アーキタイプ図鑑のプレビューや共有リンクからの復元では表示しません。

## 診断モデル

5つのレイヤーは**別系統でスコアリングし、相互に加点しません**。総合点は作らず、適職判定・求人推薦・年収予測・採用評価は行いません。

| # | レイヤー | 内容 | 設問/操作 | 出力 |
|---|---|---|---|---|
| 1 | **Personality** | Big Five（IPIP等の公開心理尺度を参考にした独自和文項目） | 25問（各特性5問） | 5特性の連続スコア 0–100 |
| 2 | **Work Style** | 会計実務の進め方（プロダクト独自4軸） | 16問（各軸4問） | 4軸の連続スコア + アーキタイプ |
| 3 | **Subject DNA** | 試験科目への興味（経験資格で科目リストを切替） | 4操作（S0–S3） | 上位3科目 |
| 4 | **Practice DNA** | 実務領域への興味（経験/好き/やりたいを区別） | 3操作（P1–P3） | 上位4領域 + バッジ |
| 5 | **Study Behavior** | 学習行動 | 8問（各1問） | 8指標の連続スコア（参考値） |

計 **49問 + 7操作 = 56回答**（20ページ・体感5〜8分）。

### Work Style 4軸

| 軸 | 記号 | 一方の極 | 他方の極 |
|---|---|---|---|
| 視座 | P / B | **精密** ディテール・数値の正確性志向 | **俯瞰** 全体構造・ビジネス文脈志向 |
| 推論 | V / X | **検証** 根拠・基準への当てはめ重視 | **探索** 仮説形成・未知の論点重視 |
| 進め方 | S / A | **構造** 計画・標準化・段取り重視 | **適応** 即応・走りながらの調整重視 |
| 作業様式 | D / C | **深掘** 独立・単独深掘り | **協働** 対話・共同作業 |

4軸の極の組合せで16のアーキタイプが決まります。アーキタイプは**Work Styleのみ**から生成し、他のレイヤーは混入させません。

### スコアリング

- **Likert**: とても+2 / やや+1 / どちらとも0 / あまり−1 / まったく−2。逆転項目は符号反転
- **欠測**: 「経験がなく判断できない」（N/A）と未回答は欠測として平均から除外する。**0点にしない**
- **Personality**: 特性ごとの有効回答平均 m → `round((m+2)/4×100)`。有効回答3問未満の特性は「判定不能」としてレイヤーごと非表示
- **Work Style**: 軸ごと4問を極方向に合計 s（−8..+8）→ `pct = round(50 + 50|s|/8)`。s≥0で左極。s=0は既定極 + 「両極型」注記
- **Study**: 各指標1問 → `(v+2)/4×100`
- **Subject DNA**: S1各+2 / S2 +3 / S3各+2 → 最大値100で正規化し上位3
- **Practice DNA**: P2各+2 / P3順位3・2・1 → 正規化し上位4。**P1（経験）は加点しない**（経験の有無を適性として扱わないため）。コア=好き×やりたい、フロンティア=未経験×やりたい

実装は [`src/scoring.js`](src/scoring.js) に集約しています。

## 画面

| 画面 | 内容 |
|---|---|
| トップ | ヒーロー + キャラクターの流れる帯 + 5レイヤーカード + PRIVACYパネル + disclaimer |
| 質問 | 4問/ページのLikert（13ページ）→ DNA操作（7ページ）。進捗バー・途中保存・N/A対応 |
| 結果 | アーキタイプのキャラクター + 5レイヤー + 日々の傾向 + Profile Map + 解説 + ダウンロード |
| アーキタイプ図鑑 | 16種の一覧。カードから個人スコアなしのプレビューを表示 |

`prefers-reduced-motion: reduce` ですべてのアニメーションを無効化します（トップの流れる帯は手でスクロールできる形に切り替わります）。選択状態は色だけでなく ✓ / 順位数字 / `aria-pressed` を併用します。

## アーキタイプのキャラクター

16のアーキタイプにはそれぞれ動物のキャラクターがいます。診断後の結果画面、図鑑カード、トップの流れる帯、ダウンロードするPNGシートで使用します。

| Code | アーキタイプ | 動物 | Code | アーキタイプ | 動物 |
|---|---|---|---|---|---|
| PVSD | 精密検証官 | ハリネズミ | BVSD | ナレッジビルダー | リス |
| PVSC | 品質ガーディアン | シェパード | BVSC | チームコーディネーター | コーギー |
| PVAD | 数字の探偵 | フクロウ | BVAD | 事業解像アナリスト | タカ |
| PVAC | 決算オペレーター | ライオン | BVAC | 対話型コンサルタント | オウム |
| PXSD | 基準設計士 | ツル | BXSD | 論点ハンター | キツネ |
| PXSC | 仕組み化アーキテクト | クモ | BXSC | クロスドメイン型 | カメレオン |
| PXAD | 独立深掘り職人 | モグラ | BXAD | 仮説ドリブン探索者 | イルカ |
| PXAC | 業務改善エンジニア | ビーバー | BXAC | 変革プロトタイパー | ネコ |

```text
assets/archetypes/{CODE}.jpg         720px  結果画面・PNGシート用
assets/archetypes/thumb/{CODE}.jpg   320px  図鑑カード・トップの帯用
```

**画像は差し替え・追加のみで反映されます。** コードは実在するファイルだけを使い、無いものは自動でグラデーション表示にフォールバックします（トップの帯からも除外されます）。ファイル名を上記の規則に合わせて置くだけで、`src/` の変更は不要です。

> **未提供: `PVAD`（数字の探偵 / フクロウ）**
> この1点だけ画像が未生成のため、現在は結果画面・図鑑ともグラデーション表示になります。`assets/archetypes/PVAD.jpg`（720px）と `assets/archetypes/thumb/PVAD.jpg`（320px）を追加すれば、そのまま表示されます。

元画像は1枚あたり約2.3MB・16枚で約33MBあるため、リポジトリには収めず、720px / 320px のJPEGに変換して同梱しています（合計約2.3MB）。各アーキタイプの `prompt`（`src/data.js`）は画像生成時のコンセプトとして保持しています。

## 構成

```text
├─ index.html               エントリ（ビルドなし）
├─ src/
│  ├─ app.js                画面切替・共有リンク復元
│  ├─ data.js               設問・軸・アーキタイプの全データ
│  ├─ scoring.js            スコアリング（設計書 §8 準拠）
│  ├─ state.js              状態と下書きの一時保存
│  ├─ export.js             PNG/JSON の生成と読み込み
│  ├─ ui.js                 最小限のDOMヘルパー
│  └─ screens/              home / quiz / result / types
├─ styles/app.css           Product UI Layer（トークン上書きを含む）
├─ assets/archetypes/       アーキタイプのキャラクター画像（720px / thumb 320px）
├─ design-system/           norimaki-tool-standards の design/ を複製
└─ scripts/dev-server.mjs   ローカル確認用の静的サーバー
```

`design-system/` は [norimaki-audit/norimaki-tool-standards](https://github.com/norimaki-audit/norimaki-tool-standards) の `design/` をそのまま持ち込んだBrand Layerです。アプリ固有の紙色地・深緑・角丸2pxへの上書きは `styles/app.css` の `:root` に集約しており、design-system 側のファイルは変更していません（更新時は上書きコピーで追従できます）。

## 注意事項

本サービスは心理学研究（IPIP等の公開心理尺度）を参考にした**独自の自己理解コンテンツ**です。妥当性検証済みの心理検査ではありません。

- 心理検査・能力検査・採用・人事評価を目的としたものではありません
- 適職判定・求人推薦・年収予測は行いません
- Work Style 4軸はプロダクト独自の軸であり、確立した心理尺度ではありません
- Study Behavior は各指標1問のため信頼性が限定的な参考値です
- 設問・アーキタイプ名・解説・画像コンセプトはすべてオリジナルです。MBTI® の設問・タイプ名称・4文字コードは使用していません

象徴ビジュアルは現在CSSグラデーションのプレースホルダで、各アーキタイプが画像生成用プロンプト（`prompt`）と2色（`c`）を保持しています。将来、生成画像に差し替えられる設計です。
